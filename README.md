## Selected work

### [done-is-a-claim](https://github.com/Grit-77/done-is-a-claim)

**Your agent says “done”. What would prove it?**

Incident-backed rules and focused skills for coding agents, with local tools for capturing and rechecking evidence. Start with a Markdown rules file; add the workflows you need.

[Read the rules](https://github.com/Grit-77/done-is-a-claim/blob/main/AGENTS.md) · [Try the demo](https://github.com/Grit-77/done-is-a-claim#watch-a-false-green)

### [dotline](https://github.com/Grit-77/dotline)

**A small mailbox between your ChatGPT dot and Claude Code.**

Send a request, claim the work, and read the reply through ordinary HTTPS. Python standard library, with no model API calls. The coding session does the work; you decide what it may authorize.

[How it works](https://github.com/Grit-77/dotline#quickstart-three-steps) · [Trust and security](https://github.com/Grit-77/dotline#trust-and-security)
